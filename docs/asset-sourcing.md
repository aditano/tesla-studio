# Newer vehicle asset sourcing

Reviewed 2026-09-07. A downloadable listing alone is not evidence of suitable geometry or permission to redistribute a mesh in this public repository.

| Vehicle | Result | Action |
| --- | --- | --- |
| Model 3 Highland | Actual GLB downloaded from a credited GitHub copy; embedded CC BY 4.0 attribution; 179,692 triangles and original textures. | Integrated. See `public/models/highland/CREDITS.md`. |
| Model Y Juniper | BloxBloger's 2025 Model Y has CC BY-NC licensing and 307,399 triangles, but the official download requires login. No clearly licensed public copy found. | Existing study remains. |
| Cybertruck | Lexyc16's CC BY 4.0 mesh was downloaded from a credited GitHub copy. It is an older concept mesh with 8,006 triangles and no detailed cabin. | Not substituted for the production-design study: wrong generation and insufficient detail for the requested upgrade. |
| Cybercab | Alternative commercial listings found; no clearly licensed, accessible free source suitable for integration verified. | Existing study remains. |

Sources reviewed:

- Highland: https://github.com/erictfree/Carbon-Footprint-AI-Visualizer/tree/af4bef33ca371b24c1f043486f09a13571f4919b/models/tesla-model-3-2024
- Juniper artist listing: https://sketchfab.com/3d-models/2025-tesla-model-y-619601e7800d418da5922c4fa7833f74
- Cybertruck credited public copy: https://github.com/prabhatsingh415/Tesla_Landing_Page/tree/456a6ba3f6e1534c40bb8d1bc932cd6766db3edb/TeslaLandingPage/public/threeDModels/tesla-cyberTruck
- Cybercab commercial candidate, with opening doors and trunk: https://www.cgtrader.com/3d-models/car/concept-car/tesla-cybercab-robotaxi
- Detailed commercial Cybercab candidate: https://www.renderhub.com/hkv-studios/2026-tesla-cybercab
- A repository containing newer Tesla body/wheel GLBs explicitly says their license is unspecified. Those files were not imported: https://github.com/Fexiven/ha-tesla-3d-card/blob/main/CREDITS.md

Commercial candidates have not been purchased or technically validated. Their licenses must also support browser delivery; a royalty-free product listing does not automatically permit publishing the raw asset in a public Git repository.
