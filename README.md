# Tesla Studio

Unofficial interactive 3D vehicle studio inspired by Tesla's in-car visualization: dark studio, liquid-glass chrome, and a high-detail WebGL digital twin.

**Live:** https://aditano.github.io/tesla-studio/

## Models

- Model 3 (Highland)
- Model Y (Juniper) with signature light bar
- Cybertruck with air suspension and tonneau
- Cybercab with butterfly doors

## Controls

- Drag to orbit, scroll to zoom
- Click doors, frunk, trunk, charge port, or tonneau to open
- Bottom left: feature animations (light bar, headlights, suspension)
- Bottom right: variant, exterior paint, interior

## Stack

React, Three.js, React Three Fiber, Drei, Tailwind CSS. Hosted on GitHub Pages.
